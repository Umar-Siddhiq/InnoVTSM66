# Professional Technical Report Format

Use this structure for Word/PDF reports unless the user provides a template.

1. Cover page
   - report title
   - project/product
   - issue/reference ID
   - version/date
   - status
2. Document control / revision history
3. Executive summary
4. Background and system context
5. Problem statement
6. Expected vs actual behavior
7. Investigation methodology and chronology
8. Technical findings
9. Root cause
10. Changes implemented
11. Code/configuration/hardware change summary
12. Validation and test matrix
13. Final working state
14. Remaining risks and pending actions
15. Handover / reproduction steps
16. Appendix
   - important logs
   - short code excerpts
   - packet examples
   - test evidence
   - specification references

Keep the main report readable. Move raw logs and long technical evidence to appendices.
